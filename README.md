# PitchPass\n\nPitchPass is your ultimate beginner's guide to the English Premier League. Learn the rules, discover your club, and keep up with the drama.\n\n## Prerequisites\n- Node.js (v18+)\n- PostgreSQL\n\n## Getting Started\n\n1. **Clone the repository:**\n   ```bash\n   git clone https://github.com/your-username/pitchpass.git\n   cd pitchpass\n   ```\n\n2. **Backend Setup:**\n   ```bash\n   cd backend\n   npm install\n   cp .env.example .env  # Add your database URI and Football API keys\n   npm run migrate\n   npm run dev\n   ```\n\n3. **Frontend Setup:**\n   ```bash\n   cd ../frontend\n   npm install\n   npm start\n   ```\n\n## Architecture\n- `frontend/`: React SPA containing pages for the Quiz, Guides, Live Hub, and Team Directory.\n- `backend/`: Express server handling API endpoints, database queries, and third-party sports data synchronization.
